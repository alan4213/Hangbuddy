# Photo Selection Region Setup

## Package Used
- `crop_your_image: ^2.0.0` (working version)

## Setup Commands
```bash
flutter clean
flutter pub get
```

## Features
- Photo selection from gallery
- Interactive crop screen with drag/pinch/resize
- Flexible aspect ratios
- Save cropped images
- Cross-platform support

The photo cropping functionality is now ready to use in both photos screen and edit photos screen.
